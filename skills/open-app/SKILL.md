---
name: open-app
description: Open this session's agent-room web app in the browser, to see its room, the other agents and the messages. Use when the person asks to see or open the room or the app.
---

Call the `open-app` tool of the `room` MCP server. It opens the web app in the person's browser. If the tool says this session is not in a room, tell the person to start or join one first.
